# Three-Phase Flow with Foam – (Lyu, 2021 inspired cases)

These cases simulates a three-phase (water–oil–gas) flow with foam in porous media in different injection/initial conditions, inspired by the simulation scenarious described by Lyu et al. (2021), using a STARS foam model.

## How to Run
    In each case directory run:

    chmod +x Allrun.sh
    ./Allrun.sh

## Physical Description

These cases consider a three-phase (water–oil–gas) flow in porous media with foam, aiming to describe foam behavior in different injection and initial conditions scenarious.

## References

- Lyu, X., Voskov, D., Tang, J., & Rossen, W. R. (2021).  
  *Simulation of foam enhanced-oil-recovery processes using operator-based linearization approach*.  
  SPE Journal, 26(04), 2287–2304.
