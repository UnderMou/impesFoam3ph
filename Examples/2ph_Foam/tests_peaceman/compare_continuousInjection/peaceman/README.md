# Foam co-injection STARS Model

This case reproduces a foam co-injection at a fixed foam quality ($f_g$) study using the STARS foam model.

## How to Run

    chmod +x Allrun.sh
    ./Allrun.sh

## Physical Description

This case considers a two-phase (water–gas) flow in porous media with foam generation, where the foam behavior is modeled using the **STARS implicit-texture model**.
